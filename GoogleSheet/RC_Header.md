# RC_Header

## Purpose

Maintains one record for each approved Rate Contract.

This sheet is the master index of all approved Rate Contracts and acts as the parent source for Purchase Order creation.

Each Rate Contract is linked to one dedicated RC Item Sheet.

## Ownership

This sheet is maintained by the Store Administration.

## Relationships

- Parent of RC Item Sheets.
- Parent source for Purchase Order Entry.
- One record represents one approved Rate Contract.

## Phase 1 Boundary

Only workbook structure and documentation are defined in Phase 1.

No Apps Script automation, formulas, validations, or sample records are implemented.
