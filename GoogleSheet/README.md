# Google Sheet Workbook Architecture

This folder documents the Google Sheet modules required by AIIMS Store ERP.

The production workbook will contain:

- `Settings`
- `RC_Header`
- `RC Item Sheets` (One dedicated sheet per approved Rate Contract)
- `PO_Entry`
- `PO_Register`
- `Receipt_Entry`
- `Receipt_Register`
- `Inspection_Verification`
- `Inspection_Register`
- `Dashboard`
- `Reports`

Phase 1 defines sheet ownership and architectural purpose only. Column-level implementation is deferred to later workflow phases.
